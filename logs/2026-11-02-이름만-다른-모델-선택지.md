# 모델을 골라도 결과가 안 바뀌던 일 — 설정이 아니라 선택 칸이 틀렸다

**상황**: 그림 생성 설정에서 모델을 "일러스트 / 실사 / Pony / MOSS Image" 중에 고를 수 있었는데, 무엇을 골라도 같은 모델로 나온다는 말을 들었습니다. 처음엔 저장이 안 되는 줄 알았어요.

**확인한 것**
1. 저장은 잘 되고 있었습니다. 문제는 모델 고르는 칸이 **두 개**(방 전용 / 일반 채팅용)였고 이름이 비슷해서, 바꾼 칸과 실제로 읽는 칸이 달랐어요. → 칸을 하나로 합쳤습니다.
2. 그래도 이상해서 그림을 만드는 서버 쪽 설명서와 코드를 열어 봤더니, **일러스트·실사·Pony가 전부 같은 모델(Krea 2)로 연결된 옛 이름**이었습니다. 넷 중 셋이 같은 모델이었던 거예요.

**고친 방법**
- 선택 칸을 실제로 있는 모델만 남겨 **"Krea 2 / MOSS Image"** 두 개로 줄이고, 화면에 모델 이름을 그대로 보이게 했습니다.
- "실사로 그려 줘" 같은 말로 모델이 바뀌는 척하던 처리도 없앴어요. 그림체는 프롬프트 문장으로 전달하고, 모델은 사용자가 고른 하나만 씁니다.
- 없어진 선택지가 다시 생기지 않게 테스트를 붙였습니다.

**배운 점**
- "저장이 안 돼요"라는 말을 들으면 저장만 보지 말고, **그 값이 실제로 무엇을 바꾸는지** 끝까지 따라가 보기.
- 화면의 선택지는 실제로 다른 결과를 내는 것만 둔다. 이름만 다른 선택지는 사용자를 속인다.
